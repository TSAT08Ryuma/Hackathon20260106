## ④どんな作品か
- 「英語学習は苦痛でつまらない」という前提そのものを疑い、“おもしろく・安く・続けられる”英語学習体験を実現することを目的とした音読学習アプリ
- 学習者が興味のあるテーマを入力すると、AI（Gemini）が約1分の英語教材を自動生成
- 生成された英文は、ブラウザ標準の音声読み上げ機能を使って即座に音読・シャドーイング可能
- 作成した教材は保存・再生・削除ができ、学習履歴として再利用可能
- 高額・退屈になりがちな既存教材に対し、「興味 × 適切な長さ × 低コスト」を重視した新しい学習アプローチを提示する作品

## ⑤工夫した点・こだわった点
- 「英語教材がおもしろくない」という課題を起点に設計し、学習内容をユーザーの関心ベースで生成する構造にした点
- 英語学習の重要要素（単語理解・発音理解・文章理解）を、1分程度の音読教材に集約し、継続しやすさを重視した点
- 高価な月額教材と比較し、API使用料ほぼ1円という極端な低コスト設計を実現した点
- AI生成部分（Node.js / Gemini API）と、データ保存部分（PHP / MySQL）を役割ごとに分離した構成にし、仕組みを理解しやすくした点
- 保存・再生・削除といった基本機能をあえてシンプルに実装し、「まず使えること」を最優先した点
